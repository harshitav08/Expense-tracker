# Expense-tracker


Simple Expense Tracker demo project.

## Tech stack
- Frontend: HTML, CSS, JavaScript (localStorage demo)
- Backend: Java (service class stub)
- Database: MySQL schema (`database/expenses.sql`)

## Features
- Add expense (title, category, amount, date)
- View all expenses (table)
- LocalStorage demo for frontend
- SQL schema for real DB

## How to run (frontend)
1. Open `frontend/index.html` in your browser.
2. To add an expense, go to `frontend/add_expense.html`.

## Notes
- Backend is a Java service layer (non-deployed) demonstrating OOP and CRUD.
- To run fully with server + DB: implement servlets, add JDBC driver, deploy to Tomcat, import `database/expenses.sql` into MySQL.
